Saya Sonang, siswa kelas 12 TKJ di SMK Bangun Nusa Bangsa.

Selama menempuh pendidikan di jurusan Teknik Komputer dan Jaringan, saya mendalami bagaimana perangkat keras, sistem operasi, dan jaringan komputer saling terhubung untuk menghadirkan layanan digital yang cepat dan aman.

Selain mengonfigurasi router MikroTik, VLAN, dan server berbasis Linux, saya juga senang membangun website portofolio dan aplikasi web interaktif menggunakan HTML, CSS, dan JavaScript. Saya percaya pemahaman jaringan yang kuat membuat saya menjadi pengembang web yang lebih teliti.
